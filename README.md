# Pricing Plans Layout

Mise en page responsive de **plans tarifaires** réalisée dans le parcours **freeCodeCamp : Responsive Web Design**. Le projet met en pratique HTML sémantique, CSS Flexbox et les états interactifs.

![Statut](https://img.shields.io/badge/Statut-Terminé-brightgreen) ![freeCodeCamp](https://img.shields.io/badge/freeCodeCamp-Responsive%20Web%20Design-0A0A23) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## Aperçu

Trois cartes tarifaires - Basic, Pro et Premium - sont disposées avec Flexbox. Chaque carte présente un prix, des fonctionnalités et un bouton d'appel à l'action.

![Capture d'écran du projet](./screenshot.png)

## Compétences travaillées

- Structuration avec HTML5 sémantique (`main`, `article`)
- Mise en page avec CSS Flexbox
- Transitions CSS
- États `:hover` et `:focus-visible`
- Organisation responsive d'une grille de cartes

## Technologies

- HTML5
- CSS3
- Flexbox
